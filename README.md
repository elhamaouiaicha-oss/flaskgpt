# FlaskGPT

Chatbot Flask avec discussions, import de fichiers, export et évaluation des réponses.

## Installation
```
poetry install
npm install
```
Créer un fichier `.env` avec `GROQ_API_KEY=votre_cle`

## Lancement
```
npx @tailwindcss/cli -i ./static/css/input.css -o ./static/dist/css/style.css --watch
poetry run flask --app app run --debug
```
Puis ouvrir http://127.0.0.1:5000/
